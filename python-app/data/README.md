# data/

Esta pasta guarda o estado de execução da aplicação Python
(`estado.json`). O arquivo é criado automaticamente na primeira execução e não
é versionado, porque contém leituras de demonstração.

Para voltar ao estado inicial, use a opção **6 — Reiniciar dados de exemplo** no
menu ou apague `estado.json` e execute `python app.py` novamente.
